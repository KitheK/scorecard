# §4.4 Font pack manifest

## Files

| Path | Role |
|------|------|
| `content/font-pack.json` | Active pack in a scaffolded project (optional until WS5) |
| `font-packs/<packId>/manifest.json` | Traced or built-in pack directory |

Type: `FontPackManifest`

Built-in ids (shortcuts): `libretto-default`, `editorial-plain`, `custom`.

`theme.json` gains optional `fontPackId`; inline `fonts` enums remain as shortcuts mapping to packs until WS5 switches Look mode.

## Validation

`validateFontPackManifest(manifest, exists?)` — when `exists` is provided, each `faces.*.woff2` path must resolve.
